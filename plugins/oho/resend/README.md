# Resend

使用自己的 Resend 账号发送事务邮件，每次发送都需要批准。

## 工具

本插件提供 1 个工具的实现和完整清单，其中 0 个读取工具可通过已配置的插件服务调用。

| 操作 | 工具标识 | 当前状态 |
| --- | --- | --- |
| 申请通过 Resend 发送邮件 | `resend_propose_send` | 等待审批接入，当前禁止执行 |

## 连接方式

安装后填写插件服务地址和连接密钥。服务需要事先连接你的 Resend 账号或配置对应密钥；安装插件本身不会完成第三方账号授权。

服务由独立插件仓库运行，启动和凭据配置见[运行说明](https://github.com/wuyuxiangX/oho-plugins/blob/main/docs/runtime.md)。Oho 按仓库版本读取清单，在连接时核对服务提供的工具定义。

修改或发送操作的处理器已经迁移，并保留审批接口。本版本的服务会拒绝这些操作；接入持久化审批和恢复执行后才能使用。
