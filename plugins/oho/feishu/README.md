# 飞书

连接中国区飞书，查看任务列表和任务详情。

## 工具

本插件提供 2 个工具的实现和完整清单，其中 2 个读取工具可通过已配置的插件服务调用。

| 操作 | 工具标识 | 当前状态 |
| --- | --- | --- |
| 查看飞书任务 | `feishu_list_my_tasks` | 连接后可读取 |
| 读取飞书任务 | `feishu_read_task` | 连接后可读取 |

## 连接方式

安装后填写插件服务地址和连接密钥。服务需要事先连接你的 飞书 账号或配置对应密钥；安装插件本身不会完成第三方账号授权。

服务由独立插件仓库运行，启动和凭据配置见[运行说明](https://github.com/wuyuxiangX/oho-plugins/blob/main/docs/runtime.md)。Oho 按仓库版本读取清单，在连接时核对服务提供的工具定义。

仅提供读取操作，不修改第三方数据。
